# Wildenhorst Badhoevedorp v0.19

Mobiele webapp/PWA voor de zaterdagmorgen dubbelcompetitie.

Belangrijk in v0.19:
- Bij Mijn koppel staat per speler hoe vaak hij dit seizoen daadwerkelijk voor een ander koppel is ingevallen, gebaseerd op gepubliceerde baanindelingen van gespeelde zaterdagen.
- Op Meer → Mijn gegevens is de tekst over enkelspelvoorkeur van het overzichtskaartje verwijderd.
- Alle verbeteringen uit v0.18 blijven behouden.

## Publiceren
Upload alle bestanden uit deze ZIP naar de hoofdmap van de GitHub Pages-repository.

## Firebase
Voor v0.19 zijn geen nieuwe Firestore-regels nodig. De gepubliceerde regels van v0.15 blijven gelden.
