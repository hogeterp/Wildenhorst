# Wildenhorst Badhoevedorp v1.18

Webapp voor de zaterdagmorgen dubbelcompetitie.

## Nieuw in v1.18

- Het privé-opmerkingenveld staat nu onder de volledige spelersregel en wordt niet meer in de smalle naamkolom gepropt.
- Op mobiel staat **📝 Mijn opmerking – alleen voor mij** met een breed invoerveld zoals bedoeld.
- De opmerking blijft automatisch opslaan en blijft uitsluitend zichtbaar voor de betreffende speler.
- Alle overige functionaliteit uit v1.17 blijft behouden.
- Versie- en cacheverwijzingen zijn gelijkgetrokken naar v1.18.

## Publiceren

Upload alle 18 bestanden naar GitHub Pages. Voor v1.18 zijn geen nieuwe Firestore-regels nodig ten opzichte van v1.17.
