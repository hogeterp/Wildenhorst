# Wildenhorst Badhoevedorp v1.12

## Nieuw in v1.12
- **Toekomstige spelerskeuzes is nu voor alle ingelogde spelers zichtbaar** via Meer → Toekomstige spelerskeuzes.
- Het overzicht is voor gewone spelers **alleen-lezen** en toont per koppel en komende zaterdag S / R / A / I / –.
- De naamweergave gebruikt dezelfde compacte naamregel als de rest van de app.
- De bestaande beheerweergave blijft ongewijzigd beschikbaar onder Beheer → Seizoen.
- Cache- en bestandsversies zijn volledig gelijkgetrokken naar v1.12.

## Publiceren
Upload alle 18 bestanden naar GitHub Pages. Voor v1.12 zijn **geen nieuwe Firestore-regels nodig** ten opzichte van v1.11; `firestore.rules` is ongewijzigd opgenomen in de ZIP.
