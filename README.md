# Wildenhorst Badhoevedorp v1.35

## Nieuw in v1.35
- **Beheer → Indeling** heeft een nieuw onderdeel **Koppel aanpassen**. De beheerder kiest een koppel en kan per vaste speler **Speelt / Reserve / Afwezig** aanpassen.
- Als beide vaste spelers afwezig zijn, kan de beheerder vanuit hetzelfde onderdeel direct een vaste speler of reserve als vervanger vastleggen.
- In **Mijn koppel** ziet het koppel duidelijk wanneer de spelerskeuze door een beheerder is aangepast.
- **Invallen dit seizoen** telt daadwerkelijk gespeelde invalbeurten robuuster vanuit de gepubliceerde baanindelingen, ook als de opgeslagen speler-ID of koppel-ID van een vervanger afwijkt.
- Alle overige functies uit v1.34 blijven behouden.
