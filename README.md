# Wildenhorst Badhoevedorp v0.27

Belangrijk in v0.27:
- Bij uitslagen staan eventuele gamepunten alleen achter de laatste set.
- Voeg je een extra set toe, dan verhuist het gamepuntenveld automatisch naar die nieuwe laatste set.
- Voorbeeld: Set 3 = 4–4 en game = 15–0.
- De aparte kaart voor lopende gamepunten is verwijderd.
- Opmerking is uit het uitslagenformulier verwijderd.
- Beheer → Uitslagen heeft een 🧪 Testdag. Testuitslagen worden niet opgeslagen en tellen niet mee in de stand.
- Handmatige puntencorrectie en het bewerken van echte opgeslagen uitslagen blijven beschikbaar.
- Versie/cache bijgewerkt naar v0.27.

Firestore:
- v0.27 gebruikt dezelfde Firestore-regels als v0.25; voor deze wijziging hoeven de regels niet opnieuw gepubliceerd te worden.
